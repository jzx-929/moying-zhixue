02 COLLABORATION WORKFLOW

团队协作流程

10人团队分为5个组别，通过清晰的接口定义与协作规范，确保各组高效协同。项目按三阶段推进，每阶段有明确的里程碑与交付物。

分组与协作关系

管理组（1人）
统筹全局，协调所有组别，对接指导教师与赛事方，管理进度与风险。
AI模型组（3人）
核心引擎，双Agent开发、LoRA微调、双RAG知识库构建，为前后端提供模型能力。
开发组（2人）
系统实现，前后端开发，对接AI模型组API，构建四大板块功能页面。
内容数据组（2人）
数据供给，国学文本与视觉数据收集标注，为RAG知识库与模型微调提供数据源。
设计测试组（2人）
质量保障，UI设计、功能测试、文档撰写与提交材料整理。
协作链路
内容数据组（数据源）→ AI模型组（模型能力）→ 开发组（系统集成）→ 设计测试组（设计/测试/文档）；管理组横向统筹全链路。

协作规范

Git 版本管理
采用 Git Flow 分支策略，main/master 为稳定分支，develop 为开发分支，feature/* 为功能分支。所有代码合并前需通过 Code Review，提交信息遵循 Conventional Commits 规范。
每日站会（15分钟）
每日固定时间召开线上站会，每人简述：昨天做了什么、今天计划做什么、遇到什么阻碍。站会由项目经理主持，控制在15分钟内，聚焦问题暴露与协调。
周报制度
每周五提交个人周报，包含本周完成事项、下周计划、风险与求助。项目经理汇总后形成项目周报，同步至指导教师与全队。
代码评审
所有 Pull Request 需至少1名组内成员 Review 通过后方可合并。核心模块（Agent工作流/RAG检索/动画生成）需2人以上 Review，确保代码质量与可维护性。
