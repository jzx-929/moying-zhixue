2编写文本清洗与分块脚本

任务说明

把原始 txt 文件清洗（去注释空行）后，按规则分块，为每块打上元数据标签。

分块规则

典籍分块方式块大小重叠
论语 / 孟子按条分（一条一块）自然条目无
道德经按章分（一章一块）自然章节无
庄子 / 史记按段落分200-500 字50 字

脚本代码

创建文件 scripts/build_rag_text.py：

import os, re, json, hashlib from pathlib import Path # ===== 1. 配置 ===== TEXT_DIR = Path("data/texts") OUTPUT = Path("data/chunks.json") SCHOOL_MAP = { "论语": "儒家", "孟子": "儒家", "道德经": "道家", "庄子": "道家", "史记": "史家", } # ===== 2. 清洗函数 ===== def clean_text(text): """去掉空行、注释标记，只保留古文原文""" lines = [l.strip() for l in text.splitlines()] lines = [l for l in lines if l and not l.startswith("//")] return "\n".join(lines) # ===== 3. 分块函数 ===== def chunk_by_paragraph(text, max_len=400, overlap=50): """长文本按段落分块，带重叠""" paragraphs = text.split("\n") chunks, current = [], "" for p in paragraphs: if len(current) + len(p) > max_len and current: chunks.append(current) current = current[-overlap:] + p # 保留尾部重叠 else: current = current + "\n" + p if current else p if current: chunks.append(current) return chunks # ===== 4. 主流程：遍历所有文本，清洗+分块 ===== all_chunks = [] for book_dir in TEXT_DIR.iterdir(): if not book_dir.is_dir(): continue book_name = book_dir.name school = SCHOOL_MAP.get(book_name, "其他") for txt_file in book_dir.glob("*.txt"): chapter = txt_file.stem raw = txt_file.read_text(encoding="utf-8") cleaned = clean_text(raw) # 论语/孟子/道德经：整篇作为一个块 if book_name in ("论语", "孟子", "道德经"): pieces = [cleaned] else: # 庄子/史记：按段落分块 pieces = chunk_by_paragraph(cleaned) for i, piece in enumerate(pieces): chunk_id = hashlib.md5(f"{book_name}_{chapter}_{i}".encode()).hexdigest()[:12] all_chunks.append({ "id": chunk_id, "text": piece, "metadata": { "source": book_name, "chapter": chapter, "school": school, "chunk_index": i } }) # ===== 5. 保存 ===== OUTPUT.write_text(json.dumps(all_chunks, ensure_ascii=False, indent=2), encoding="utf-8") print(f"分块完成：共 {len(all_chunks)} 个文本块，已保存到 {OUTPUT}")
运行前准备：确保 data/texts/ 目录下已有整理好的 txt 文件。pip install chromadb 也要先装好。

3文本入库到 Chroma 向量数据库

任务说明

将上一步生成的分块数据存入 Chroma 向量数据库，实现语义检索能力。

入库脚本

创建文件 scripts/build_rag.py：

import chromadb import json from pathlib import Path # ===== 1. 连接 Chroma（本地持久化） ===== client = chromadb.PersistentClient(path="data/chroma_db") collection = client.get_or_create_collection( name="guoxue_texts", metadata={"description": "诸子百家国学文本库"} ) # ===== 2. 加载分块数据 ===== chunks = json.loads(Path("data/chunks.json").read_text(encoding="utf-8")) print(f"加载了 {len(chunks)} 个文本块") # ===== 3. 批量入库（每批最多 500 条） ===== BATCH = 500 for i in range(0, len(chunks), BATCH): batch = chunks[i:i+BATCH] collection.add( ids=[c["id"] for c in batch], documents=[c["text"] for c in batch], metadatas=[c["metadata"] for c in batch] ) print(f"已入库 {min(i+BATCH, len(chunks))}/{len(chunks)}") print("入库完成！") # ===== 4. 验证：测试检索 ===== results = collection.query( query_texts=["孔子论学习"], n_results=3 ) print("\n=== 检索测试：'孔子论学习' ===") for doc, meta in zip(results["documents"][0], results["metadatas"][0]): print(f"[{meta['source']}·{meta['chapter']}] {doc[:80]}...")
验证标准：运行脚本后，检索"孔子论学习"应该能召回《论语》相关段落。如果召回结果不对，检查分块是否正确。

4配置双 Agent（星火星辰平台）

任务说明

在星火大模型平台（ai.fifedu.com）上创建两个 Agent，分别负责文本转化和画面风格约束。

Agent 1：文改 Agent

职责：古文解析 → 白话翻译 → 剧本拆分 → 分镜文案

操作步骤：

  1. 登录 ai.fifedu.com，进入星辰 Agent 开发平台
  2. 点击「创建 Agent」，名称填 墨影智学-文改Agent
  3. 在「知识库」中挂载上一步建好的 Chroma 文本库
  4. 在「System Prompt」中粘贴以下配置：
你是「墨影智学·文改Agent」，专门负责国学典籍的文本转化工作。 【能力】 1. 古文解析：理解诸子百家原文的含义、典故、修辞手法 2. 白话翻译：将古文翻译为通俗易懂的现代汉语 3. 剧本拆分：将叙事文本拆分为剧本格式（场景/角色/对话/旁白） 4. 分镜文案：将剧本转化为分镜描述（镜头号/画面描述/文字/时长） 【规则】 - 引用原文时必须标注出处（如《论语·学而》） - 翻译要忠于原意，不得编造内容 - 分镜描述要具体可视化，为画面Agent提供可执行的描述 - 输出格式统一为 JSON，包含字段：source, translation, script, storyboard 【输出示例】 { "source": "《论语·学而》", "translation": "孔子说：学习了知识并按时温习，不也是很愉快吗？", "script": {"scene": "学堂", "role": "孔子", "dialogue": "...", "narration": "..."}, "storyboard": [{"shot": 1, "visual": "学堂全景", "text": "子曰", "duration": "3s"}] }

Agent 2：墨影画风 Agent

职责：接收分镜文案 → 生成水墨画面构图 → 约束线条/留白/风格

操作步骤：

  1. 同样在星辰平台创建新 Agent，名称填 墨影智学-墨影画风Agent
  2. 挂载视觉知识库（蔡志忠漫画分格图集描述数据）
  3. 在「System Prompt」中粘贴以下配置：
你是「墨影智学·墨影画风Agent」，负责水墨动画画面的风格约束和生成指导。 【能力】 1. 画面构图：根据分镜文案，设计水墨画构图（主体位置/远近虚实/留白比例） 2. 风格约束：确保所有画面符合蔡志忠水墨漫画范式 3. 线条描述：为每帧画面生成具体的线条描述（粗细/疏密/方向） 4. 连帧建议：为连续画面提供过渡建议，保证动画流畅性 【风格规则】 - 线条：以简练为主，单帧不超过 5 条主要线条 - 构图：留白面积 ≥ 40%，主体偏置（不居中） - 色调：纯水墨，仅用墨色浓淡变化，不加彩色 - 人物：简约写意，面部不画五官细节（蔡志忠风格） 【输出格式】 { "frames": [ { "shot": 1, "composition": "左侧人物偏置，右侧大面积留白", "lines": [{"type": "人物轮廓", "weight": "中", "count": 3}], "ink_density": "淡墨为主，人物衣褶用浓墨", "whitespace": "55%" } ] }

5打通双 Agent 链路（FastAPI 编排）

任务说明

用 FastAPI 接口串联两个 Agent，实现"古文输入 → 文改Agent → 画风Agent → 输出"的完整链路。

协作流程

用户输入古文
→
文改Agent
挂载文本RAG
→
白话文+剧本+分镜
→
墨影画风Agent
挂载视觉RAG
→
画面构图+线条约束

接口代码

创建文件 backend/api/agents.py：

from fastapi import APIRouter, HTTPException from pydantic import BaseModel import httpx router = APIRouter(prefix="/api") # 星火 Agent 配置（替换为实际 ID 和密钥） SPARK_API = "https://spark-api.example.com/v1/agents/run" WENGAI_AGENT_ID = "文改Agent的ID" MOYING_AGENT_ID = "墨影画风Agent的ID" API_KEY = "你的星火API密钥" class GenerateRequest(BaseModel): text: str # 用户输入的古文 mode: str = "full" # full=完整链路, text=仅文改, visual=仅画风 async def call_agent(agent_id: str, user_input: str): """调用星火 Agent 接口""" async with httpx.AsyncClient(timeout=60) as client: resp = await client.post( SPARK_API, headers={"Authorization": f"Bearer {API_KEY}"}, json={"agent_id": agent_id, "input": user_input} ) if resp.status_code != 200: raise HTTPException(500, "Agent 调用失败") return resp.json() @router.post("/generate") async def generate(req: GenerateRequest): result = {} # Step 1: 调用文改Agent if req.mode in ("full", "text"): wengai = await call_agent(WENGAI_AGENT_ID, req.text) result["text_output"] = wengai if req.mode == "text": return result # Step 2: 把文改Agent的分镜输出传给画风Agent storyboard = wengai.get("storyboard", "") if req.mode in ("full", "visual"): input_text = storyboard if req.mode == "full" else req.text moying = await call_agent(MOYING_AGENT_ID, input_text) result["visual_output"] = moying return result
