# 墨影智学 —— 文本-漫画-动画跨媒介教学智能体

> 面向人文通识一流学科建设，基于星火大模型研发学科垂类教学智能体。
> 系统构建文本、漫画、动画三态双向转化技术链路，全面覆盖课程教学与科研全流程。

## 项目简介

本项目参加挑战杯竞赛 XH-202620「面向一流学科建设的学科垂类大模型与创新应用开发」（发榜单位：科大讯飞股份有限公司）。

系统以蔡志忠国学漫画范式为视觉约束，构建国学文本到极简水墨动画的标准化自动生产管线，打通"教学—创作—科研"闭环：

- **助教场景**：智能备课、多模态课件一键生成、各类作业自动批阅
- **助学场景**：经典文本可视化解读、多模态对照学习
- **助研场景**：图文传播规律的量化分析，为学科研究提供数据支撑

## 三大核心特色

### 特色1：独家双叙事赛道 + 文漫互转
- **赛道A**：白话小说影视改编（小说→剧本→多风格短片）
- **赛道B**：国学典籍水墨动画（对标蔡志忠范式，古文→分镜→水墨动画）
- **文漫互转**：上传漫画→OCR→还原古文；输入古文→生成漫画画面描述

### 特色2：教学场景国学实训专属模式
- 助教：粘贴诸子百家原文，一键输出白话文剧本 + 分镜稿 + 水墨动画
- 助学：漫画式写作训练，对照蔡志忠叙事节奏双维度辅导
- 助研：蔡志忠图像叙事量化研究工具（画面元素识别 + 构图规律统计 + 可视化图谱）

### 特色3：专属垂类模型技术壁垒
- 双数据集：文本库（诸子百家/唐诗/史记/戏剧教材）+ 视觉库（蔡志忠漫画分格图集）
- 双Agent：文改Agent（古文解析/剧本拆分）+ 墨影画风Agent（线条/构图/留白约束）
- 工作流：古文→分镜文案→线稿漫画→连续水墨动画

## 技术栈

| 层级 | 技术选型 |
|------|----------|
| 前端 | Vue 3 + TailwindCSS + ECharts + Canvas API |
| 后端 | Python FastAPI + Celery 异步任务队列 |
| AI模型 | 讯飞星火大模型 + 水墨LoRA微调 + 星辰Agent双智能体 |
| 知识库 | 双RAG（国学文本库 + 国风漫画图库）+ Chroma向量数据库 |
| 存储 | MinIO对象存储 + PostgreSQL |
| 部署 | Docker + Nginx |

## Web四大板块

1. **文影创作坊** — 小说→剧本→多风格视频
2. **墨漫工坊** — 古文↔蔡志忠漫画动画（核心特色页）
3. **教学工作台** — 教师备课 + 作业批改
4. **数字人文实验室** — 漫画图像科研分析
